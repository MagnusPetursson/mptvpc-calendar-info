# MPTVPC Calendar information pages

Standalone static homepage and privacy notice for the private MPTVPC Calendar OAuth client.

- No JavaScript
- No analytics, trackers, fonts, or external assets
- No calendar data or OAuth credentials

Published with GitHub Pages at https://magnusp.is/mptvpc-calendar-info/.

Local preview:

```sh
python3 -m http.server --directory . 8765
```
